Simple and fast cross-platform hard drive scanner for checking what's consuming the space on your computer. Simplistic by design.

To download, check "downloads", find your corresponding operating system folder and click on the file inside. This will take you to the a page where on the top right you'll see a download button saying "download raw file" when hovered over. You can then click this button to download the build. After that, simply run the installer / setup file and your OS will install the app.

As I have no Linux machine and didn't want to bother setting up Docker, there is no Linux build option on this repository. Feel free to fork/clone this and create your own Linux build by running the following after making sure you're on a Node version of `20.11.1` or above:

```
npm i
npm run build
```
